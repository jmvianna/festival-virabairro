# Festival ViraBairro — Simulado prático resolvido

Notebook `fest_virabairro_resolvido.ipynb` com as 8 questões do simulado prático,
resolvidas e comentadas em português, usando os dados fornecidos por você.

## Estrutura

- `fest_virabairro_resolvido.ipynb`: notebook completo, já executado.
- `dados/publicacoes_brutas.csv`, `dados/publicacoes_analise.csv`,
  `dados/dicionario-festival-virabairro.md`: mesmos arquivos que você enviou,
  organizados na pasta `dados/` (mesmo caminho relativo usado no código).

## Como abrir

- **Jupyter/local**: mantenha o `.ipynb` e a pasta `dados/` no mesmo diretório e abra
  normalmente (`jupyter notebook` ou VS Code).
- **Google Colab**: faça upload do `.ipynb` e da pasta `dados/` (ou monte o Google Drive
  com essa estrutura) antes de rodar as células.

## O que está pronto e o que ficou por sua conta

- Todo o código (limpeza dos dados, tabelas, gráficos e os três modelos de machine
  learning) está resolvido, testado com os dados reais e comentado linha a linha.
- As células de **resposta interpretativa** ("Resposta da Questão X") foram deixadas
  como pontos-guia, não como texto pronto — o próprio enunciado da Questão 8 pede que
  "as decisões e interpretações" sejam suas, e isso vale para o simulado inteiro.
